# 天命人（大圣套）VS 真大圣 · 10 秒文生视频提示词

> 模式：T2VA（纯文生视频，无参考图）
> 目标模型：MiniMax H3（本项目 yz 工作流）
> 时长：10.00 秒 · 比例建议 16:9
> 依据：`h3-prompt-writing` 技能 —— 三字段结构 `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music`，T2VA 无对齐指令，首镜不写时间戳，后续镜头 `At 00:0X.XXX, the camera cuts to...` 严格递增且不超时长。

## 一 · 角色设定（两版共用）

| | 天命人（Destined One） | 真大圣（True Great Sage） |
|---|---|---|
| 体型 | 精瘦、窄肩、动作轻 | 更宽更重、肩背厚实 |
| 毛色 | 棕黑短毛 | 银白长毛、带灰绺 |
| 甲 | **崭新大圣套**：鳞叠金片 + 暗红衬里 + 凤翅紫金冠 + 血红披风 | **同款剪裁但暗铜金**、甲片崩口带深划痕、披风下摆撕碎 |
| 兵器 | 如意金箍棒：亮金、箍上云纹清晰 | 同款但更暗更长，两端金箍凹陷 |
| 用途 | 画面左侧 | 画面右侧 |

> 两人穿同款甲，靠**甲色与磨损**区分，不靠甲型 —— 这是画面读得懂的关键。

## 二 · 场景与影调

- 断崖石台悬在金色云海之上，低角度夕阳逆光
- 灰烬/火星悬浮，体积光穿过云层
- 冲击波把云海推开成环形坑、碎石反重力上浮
- 材质要求：甲片浮雕可辨、金属反出火花、毛发单根可见、石面碎屑颗粒清晰
