## 三 · @ 卡片：三个叠加的缺陷

### ① 图不解码（「没有预览」的真因）

```js
const blob = new Blob([buf], { type: "" });     ← 空 MIME
preview: URL.createObjectURL(blob)
```
`<img>` 拿到 `type:""` 的 blob URL 无法判断怎么解码，**静默失败**：
DOM 里有元素、有尺寸、`src` 也非空，只有 `naturalWidth === 0`。

修：`mimeFromName()` 按扩展名给正确 MIME。

### ② 有两条构造路径（§6.43 又一次）

反向断言「不许有 type 为空的 Blob」抓出了第二条：

```
fetchAsFilePayload   → new Blob([buf], { type: "" })        ← 第一次修的
刷新后恢复的那条       → new Blob([buf])                     ← 完全不传 type，等价
```

⇒ 刷新后从 sessionStorage 恢复的 chip 依然白块。

### ③ 框不跟随文字

```
根因：<select> 里 10 个用途选项（动作/表情、角色外观、物品/道具外观…）
      浏览器按【最长选项】算 select 固有宽度，width:100% 又传给 chip
      ⇒ 可见文字 60px，胶囊 239px
修：select 改 width:0 + minWidth:100%（不占位但铺满）
```

### ④ 缩略图位置

```
第一版 left:-18px  → 落在 chip 外，压住前一个词
第二版 left:2px + paddingLeft:17px → 胶囊被撑宽，撞进后一个 chip，重影
最终   left:0       → 盖住 `@`（透明占位字符），不压任何可见文字
```

### ⑤ 悬停大图（主人说「做不了就放按钮」）

做得到，而且比按钮好（少一次点击）：

```
鼠标停在 13px 缩略图上 → 浮出 180px 大图
· 浮层 append 到 document.body（祖先有 overflow:hidden，挂在 chip 里会被裁）
· position:fixed + z-index 极大值
· pointer-events:none（不挡鼠标）
· 靠近边缘时翻转（默认向上弹，上方不够就翻下方）
```

## 四 · 轨道高度：我锁死了，主人当场纠正

```
第一版 minSize=15 → 时间轴能压到 15%，轨道区只剩 60px，一条都看不全
第二版 minSize=58 → 五条全看到，但【高度锁死】，主人明确否掉
第三版 minSize=26 → 只保证「至少一条轨道完整可见」，五条靠默认值 + 滚动
                   主内容 max 74 + 时间轴 min 26 = 100（互补）
```

**实测**：

| 拖动到 | 面板高 | 轨道区 | 完整可见轨道 |
|---|---|---|---|
| 最小（26%） | 166px | 63px | **1 条**（其余滚动） |
| 最大（70%） | 427px | 324px | **5 条全部** |

这正是主人要的：「最短缩到一个轨道的高度即可」。

```

   报错指向注释位置，看起来毫无问题。已有断言：只能有 2 个反引号。

③ 函数自引用 ⇒ 无限递归
   track-placement.ts 原本有 getDisplayTracks，我 import 同名函数并把函数体
   改成 return [...getDisplayTracks(...)] ⇒ 调用自己。

④ 我自己写的对齐层把命名框的圆角压回去了
   input:not(...) 通配 (0,3,0) > header input[type=text] (0,2,1)。

⑤ Tailwind 任意值类 max-w-[16rem] 没被生成
   computed maxWidth = none。改成在覆盖层显式写。

⑥ 改上游源码没重跑上游构建
   payload 里搜不到改动 ⇒ 界面没变。判据：改完必须看产物里有没有新字符串。
```

**六条的共同点**：都是「代码看起来改对了，但运行时没生效」。判据都是**看产物/看运行时的值**，不是看源码。
