## 三 · 执行计划

### 阶段 A · 打地基（先做，因为后面全依赖它）

```
A1  把 --st-* 改成从 --dsw-* 派生
    bg        → var(--dsw-alias-bg-base)
    panel     → var(--dsw-alias-bg-layer-1)
    controls  → var(--dsw-alias-bg-layer-2)
    sunken    → var(--dsw-alias-bg-base)（暗一号）
    modal     → var(--dsw-alias-bg-layer-1)
    fg        → var(--dsw-alias-label-primary)
    divider/panel-border/controls-border → var(--dsw-alias-border-l1)
    fg-rgb / controls-rgb → 保留（是 rgb 分量，token 给不出，需从 fg 派生的地方单独处理）
    ★ 派生失败时必须有 fallback 到原硬编码值（DSH 换版本丢 token 时不至于全黑）

A2  写「DSH 原生基准」量测脚本
    输出 JSON：页签/工具条按钮/主按钮/小按钮的 尺寸·字号·字重·圆角·padding
    用途：后面所有断言都以它为准，不写死数字
```

### 阶段 B · 时间轴尺寸与 i18n

```
B1  控件 32×32 → 28×28，字号 14px → 13px
    ★ 主按钮（导出）保持分层：38px 高 / 14px 字
    ★ 时间码按钮 85×22 已经接近 DSH 小按钮（23×22），不动

B2  标尺刻度改「秒」
    现状 10f/20f/6f/16f/2f/12f → 目标 0s/1s/2s/3s…（单调递增）
    ★ 必须保留帧精度供内部使用，只改【显示】

B3  aria-label / title 中文化
    Select Main Track track  → 选择主轨
    Ripple                   → 波纹编辑
    Video                    → 视频
    Timeline                 → 时间轴
    Click to edit time       → 点击修改时间
```

### 阶段 C · 视频工作台 4 个残留

```
C1  popover 三个边界：点外关 / Esc 关 / 窄视口不超屏 / 暗色底对比
C2  删 __AT_DEBUG__ 探针（grep 零命中 + @ 引用仍正常）
C3  空态接实时资产数（从 /library 取，不写死）
C4  漏翻检测脚本（能列出非白名单英文，退出码有意义，登记进 verify-all）
```
