## 二 · 导出对话框：修了四轮，每轮原因不同

```
第一轮  给 PopoverContent 加 ac-scope 类
        → 内部元素救活了（display:flex），但容器自己 display 仍是 block、宽 231px
        原因：规则是 `.ac-scope .flex`（后代选择器），
             容器自己同时是 .ac-scope 和 .flex，不构成「后代」关系

第二轮  外面再包一层带 ac-scope 的 div
        → inScope === false，包裹层是空的
        原因：Radix 的 PopoverContent 自己 portal 到 body，不受外层 div 约束

第三轮  回到「容器自己带类」+ 补【组合选择器】
        .ac-scope.ac-portal-surface.flex { display:flex }
        → 宽度 320px、display:flex、内部 gap 16px ✅

第四轮  文字对比度
        → 「格式/质量/音频」rgb(174,180,188) 2.1:1
          「保存位置」纯白 1.05:1（完全看不见）
        原因：portal 出去的浮层不带 theme-light 类，
             用的是暗色那套 --muted-foreground / --foreground
        修：用 DSH 的 label-secondary / label-primary token 覆盖
```

**第五轮（顺手）**：折叠分区看不到当前值
```
Section 是 collapsible + defaultOpen={false}，
但 SectionHeader 没传 trailing ⇒ 折叠时右侧空着，
用户无法知道自己选的是什么格式，必须每次点开看。
⇒ 补 trailing：「格式 MP4 | 质量 较高·推荐 | 音频 包含」
```

## 三 · 轨道错位：只在面板极矮时出现（如实登记）

实测数据（视口 914px）：

| 时间轴占比 | section 高 | 第一轨偏移 | 对齐 |
|---|---|---|---|
| 22% | 156px | −98px | ❌ 溢出 |
| 35% | 210px | −44px | ❌ |
| 45% | 269px | +15px | ✅ |
| 50% | 298px | +44px | ✅ |
| 70% | 417px | +94px | ✅ |

**根因**：内容容器用 `min-h-full`（`min-height:100%`），
在 `overflow:auto` 容器里，百分比高度的基准是**容器可视高度**。
容器被 flex 压缩到比内容矮（63px vs 251px）时，
内容以 63px 为基准向上布局 ⇒ 起点跑到容器顶部之外。

**已做的两处修**：
1. `ScrollArea` 加 `min-h-0`（让它能真正收缩而不是撑破父级）
2. 内容容器 `min-h-full` → `min-h-0 flex-1`

**当前状态**：默认 42/58 下完全对齐；压到 35% 以下仍会溢出。

**彻底修需要**：给轨道内容容器加 `overflow-anchor` 或改成非百分比高度，
属上游结构改动（影响命中测试坐标系），**未做，已登记**。

## 四 · 无障碍（子代理以用户视角发现的，开发视角最难发现）

### 滑块 aria-label 透传失效

```tsx
// 调用方写了
<Slider aria-label="播放进度" ... />
// 但实测 querySelectorAll('[role=slider]') 读到的 aria-label 全是 null
```

**根因**：Radix 把 `role="slider"` 放在 **Thumb** 上，不在 Root 上。
给 Root 传 aria-label，accessible name 计算拿不到。

**修**：`Slider` 组件把 `aria-label` / `aria-labelledby` 显式透传给 Thumb。

**实测**：`播放进度` / `时间轴缩放` 都读到了。

### 18 个图标按钮无可访问名称

```
修前：时间轴工具条 18 个 28×28 图标按钮
      aria-label / title / textContent 全为空
      ⇒ 读屏用户只会听到「按钮」
修后：2 个（场景选择器内部）
```

**修法**：
- `ToolbarButton` 把 `tooltip` 同时挂成 `aria-label` + `title`（一次修 12 个）
- 缩放 ± 按钮补「放大/缩小时间轴」
- 播放按钮补「播放/暂停」（随状态变）
- 全屏按钮补「全屏预览」
- 视图切换 / 排序按钮补标签
- 场景选择器右半补「切换场景」

## 八 · ⚠ 本轮发生的一次严重事故（必须记住）

**我用全局字符串替换中文化 `session.ts`，把整个文件毁了。**

```powershell
# 我写的（错的）：
$c = $c.Replace('message: "Select a keyframe to edit its curve.",', '...')
# 实际发生：
#   PowerShell 的 -replace / .Replace 在这种长串上出了偏差，
#   把文件里所有 'm' 替换成了 'e' ——
#   import → ieport, from → froe, message → seeage
```

**判据**：构建报 `Expected ";" but found "{"` 指向第 1 行 `ieport {`。

**恢复**：`_upstream\artcraft-src\`（参考树）里有完整原版，直接覆盖恢复。

**教训（写进纪律）**：
- 改源码文本时，**用行级精确匹配**（`$lines | ForEach-Object { if ($_ -match '精确正则') ... }`），
  不要对整个文件做 `-replace`
- 改完立刻验**文件头 3 行**是否还是 `import { ... }` —— 这次就是靠这个发现的
- 参考树 `artcraft-src\` 是有价值的：**没有它这次只能重建文件**
