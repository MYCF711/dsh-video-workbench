## 三 · 复跑确认属实的 8 条

### ① 导出对话框塌陷（修了四轮）

```
第一轮  给 PopoverContent 加 ac-scope
        → 内部救活（display:flex），容器自己仍 block、宽 231px
        原因：规则是 `.ac-scope .flex`（后代选择器），
             容器自己做不了自己的后代

第二轮  外面包一层带 ac-scope 的 div
        → inScope === false，包裹层是空的
        原因：Radix 自己 portal 到 body，包不住

第三轮  回到「容器自己带类」+ 补【组合选择器】
        .ac-scope.ac-portal-surface.flex { display:flex }
        → 宽 320px、display:flex、内部 gap 16px ✅

第四轮  对比度
        「格式/质量/音频」rgb(174,180,188) 2.1:1
        「保存位置」纯白 1.05:1（完全看不见）
        原因：portal 浮层不带 theme-light，用暗色 --foreground
        修：用 DSH label-secondary / label-primary token

第五轮（顺手）折叠分区看不到当前值
        Section 是 collapsible+defaultOpen={false}，
        SectionHeader 没传 trailing ⇒ 右侧空着
        ⇒ 补「格式 MP4 | 质量 较高·推荐 | 音频 包含」
```

**实测**：宽 320px / display:flex / gap 16px / 对比度失败 0 项。

### ② 空工程下「点了没反应」

```
修前：分割 / 向左分割 / 向右分割 / 复制片段 / 删除片段
      可点，但什么都不发生（无 toast、无变化）
修后：5 个全部 disabled=true + opacity 0.5
      缩放类（缩小/放大/行高）保持可用 —— 它们不依赖选中片段
```

**为什么这条最值得修**：「点了没反应」比「报错」更差 —— 报错至少说明系统听到了。

### ③ 18 个图标按钮无可访问名称

```
修前：时间轴工具条 18 个 28×28 图标按钮
      aria-label / title / textContent 全为空
修后：0 个
```

修法：
- `ToolbarButton` 把 `tooltip` 同时挂成 `aria-label` + `title`（一次修 12 个）
- 缩放 ±、播放、全屏、视图切换、排序、场景切换 逐个补

### ④ 滑块 aria-label 透传失效

`role="slider"` 在 **Thumb** 上不在 Root 上，给 Root 传的 aria-label 拿不到。
⇒ `Slider` 组件把 `aria-label` / `aria-labelledby` 显式透传给 Thumb。
实测：`播放进度` / `时间轴缩放` 都读到了。

### ⑤ SVG `<title>` 未中文化（第 3 轮扫描才发现）

```
17 个 <title>，14 个是英文
「Ripple」「Font」「Shapes」「Mirror」「Bezier curve editor」…
★ 虽然 svg 标了 aria-hidden，但 <title> 仍参与 accessible name 计算
⇒ 自动化读到的按钮名是 "Ripple"，而 tooltip 写着「波纹编辑」
修：14 个改中文；剩 3 个品牌名（Vercel / Marble / Data Buddy）不译
```

**为什么前两轮漏掉**：我扫的是 `aria-label=` / `title=` 属性、`tooltip=` / `label=`、
直接 JSX 文本 —— **svg 内部的 `<title>` 子元素不在这些模式里**。
