## 三 · 关于「自动识别语音」—— 本机做不了，如实说明

**实测清单**：

| 检查项 | 结果 |
|---|---|
| `whisper` / `whisper-ctranslate2` / `faster-whisper` | ❌ 全部没有 |
| `ollama`（本地大模型） | ❌ 没有 |
| ComfyUI 的 24 个 custom_nodes | ❌ 无任何 ASR / 语音识别 |
| ComfyUI models | ❌ 只有 `audio_encoders`，无 whisper 模型 |
| `ffmpeg` | ✅ 有（能抽音频，但抽出来也没人听） |

⇒ **「听音频自动转文字」本机不具备**，装一个 whisper 模型是几个 GB 的事，
不在 UI 收口范围内。

**处理方式**：面板里明确写着「本机未安装语音识别模型，所以不会自动听写」，
**不做假按钮**。这与 §6.29 的纪律同源：

> 宁可拦住，也不要让用户以为功能生效了。

## 四 · 三个实现决策（都有理由）

### ① 按段生成，不是一次生成一整段

字幕轨上每个元素 = 一条字幕。分开才能单独调时间、单独改文字、单独删。
如果生成一整段，用户要自己切 —— 那等于没做。

### ② 显式指定字幕轨，不用 `auto`

```
placement: { mode: "explicit", trackId: "track_overlay_text" }
```

因为 `auto + firstAvailable` 会找「第一个装得下的 text 轨」，
而字幕元素本来就首尾相接，很容易装不下 ⇒ 它会新建一条新 text 轨。
用户要的是「都放进字幕轨」，不是「生成一堆新轨」。

（找不到字幕轨时才 fallback 到 auto。）

### ③ 字幕样式与普通文字不同

```
普通文字：居中、无背景（可能是标题、贴纸字、画中画说明）
字幕：    贴底 88%、深色半透明衬底、字号偏小
```

**位置必须按画布高度算，不能写死像素**：

```
实测 preview-coords.ts:74 → canvasY = canvasHeight / 2 + positionY
⇒ transform.positionY 的单位是【像素】，不是百分比

写 38 在 1080p 上只下移 38px（画面 3.5%），等于没动；
而在 480p 上又会偏多。

正确做法：positionY = 0.38 × canvasHeight
```

## 五 · 踩到并修掉的一个坑

```
报错：Cannot read properties of undefined (reading 'params')

我写：DEFAULTS.text.element.element.params
实际：DEFAULTS.text.element.params
      （defaults.ts:88 是 text: { element: defaultTextElement }，
        而 defaultTextElement 自己就有 params，我多写了一层）
```

⇒ 教训：`DEFAULTS.xxx.element` 这个名字有歧义 ——
`element` 在这里不是「元素」而是「默认参数集」。写路径前要对着
`defaults.ts` 的导出结构逐层数。
