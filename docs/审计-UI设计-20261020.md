## 一句话结论

**结构（层级）基本对，但缺少三个系统：间距阶、字重阶、颜色阶。**
这三处缺失导致 15 处零散的 `off-system` 值 —— 按 skill 的说法，
这是「缺失系统」这一个系统性问题的 15 个症状，不是 15 个独立缺陷。

## Systemic · 系统性问题（这才是报告的价值）

### S1 · 没有间距阶

```
实测非 4 倍数的间距值：2, 3, 5, 6, 7, 10, 18, 22
```

规则 §1.5：「Every value comes from a system. No hand-tuned one-offs.」

**根因**：我的间距是从「紧」往上加的（§3.1.1 明确说这是错的方向：
「Was spacing added up from tight, or removed down from loose?」）。
每次觉得挤就加 1px，于是出现了 3/5/7 这种值。

**修法**：定一套 4 的倍数阶，全部替换。**这是一次全局 sed，不是逐个调。**

---

### S2 · 没有字重阶

用 400/500/600 三档，而书里说要两档。

**注意这不是「三种都难看」，而是「500 和 600 的差别用户看不出来，只增加字体加载体积」。**

---

### S3 · 颜色没有语义层

```
--dsw-* 109 处（好）
硬编码 rgba 91 处（不好 —— chip、hover、遮罩全在这里）
```

这些硬编码里有一部分是必要的（半透明遮罩、阴影），但 chip 的三种蓝
（`.10` 底 / `.30` 边 / `.60` 标记条）**应该是一个 token 的三个档**，不是三个散落的字面量。
