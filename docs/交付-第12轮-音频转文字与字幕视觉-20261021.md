## 二 · 为什么用 whisper 而不是 Windows 自带识别器

我先实测了 **Windows 自带的 System.Speech 中文识别器**（`zh-CN / MS-2052-80-DESK`），
它确实能用，但它有两个硬伤：

| | Windows 自带 | faster-whisper |
|---|---|---|
| 时间戳 | ❌ **不给** | ✅ segment 级 start/end |
| 纯音乐 | ❌ **硬凑字**（实测 16 秒纯音乐凑出「然而阿」） | ✅ 输出 0 段 |
| 准确率 | 88.1% 平均（5 场景） | **100%**（16 字 / 40 字闭环） |

**时间戳是字幕的命门** —— 没有它就没法按口型切，只能均分。

### 准确率实测（TTS 已知文本闭环 + 编辑距离）

```
16 字：100.0%
40 字：100.0%
```

「闭环」的意思是：TTS 合成已知文本 → 识别器转写回来 → 逐字比对。

## 四 · 字幕视觉（主人的第二个要求）

### 改了什么

| | 修前 | 修后 |
|---|---|---|
| 背景 | 深色半透明**衬底** | **完全透明**（`background.enabled: false`） |
| 描边 | 无 | **黑描边**（白字黑边，剪映/PR 标准） |
| 字体 | Arial | **微软雅黑**加粗 |
| 字号 | 11（≈132px @1080p，太大） | **6.5（≈78px @1080p）** |

### 为什么选微软雅黑（实测，不是猜）

我在浏览器 canvas 里渲染「永」字比像素指纹：

| 字体 | 暗像素数 | 生效 |
|---|---|---|
| sans-serif（fallback） | 547 | 基准 |
| **Microsoft YaHei** | **568** | ✅ |
| SimHei | 506 | ✅（笔画过硬） |
| SimSun | 301 | ✅（宋体太细，字幕偏弱） |
| DengXian | 385 | ✅（等线偏细） |
| Noto Sans SC | 547 | ❌ **与 fallback 相同 = 未生效** |

微软雅黑是 Windows 默认中文 UI 字体 —— 人人天天在看，不需要适应。

### 字号为什么是 6.5

`primitives.ts` 里：
```js
scaledFontSize = text.fontSize * (canvasHeight / FONT_SIZE_SCALE_REFERENCE)
FONT_SIZE_SCALE_REFERENCE = 90
```

```
6.5 × (1080 / 90) = 78px    ← 1080p 字幕的行业标准
6.5 × (720 / 90)  = 52px    ← 720p 自动缩小
```

**描边宽度按同样公式缩放**：`0.33 × 12 × 2 = 7.9px`，
描边/字号 = **10.2%**，正落在业界 8~12% 区间。

### 描边是怎么实现的（这是新加的能力）

本项目原本**没有描边参数** —— 只有 mask（文字蒙版）里有 `strokeText`，
普通字幕走不到那条路。所以改了三处：

```
① lib/text/primitives.ts
   drawMeasuredTextLayout 加 outlineColor / outlineWidth
   ★ 先描边后填字（反过来会让字变细、笔画糊在一起）

② lib/text/measure-element.ts
   解析 outline.width / outline.color（走 resolveNumberAtTime，支持关键帧）

③ lib/services/renderer/nodes/text-node.ts
   把参数传给渲染

④ lib/params/registry.ts
   加 "描边宽度" / "描边颜色" —— 属性面板能调
```

**★ 默认宽度 0 ⇒ 文本面板拖出来的普通文字行为完全不变。**
只有字幕显式设了 `outline.width` 才描边。

## 五 · 踩到并修掉的坑

### ① 临时 wav 写 `%TEMP%` 被沙箱拦

```
报错：Error opening output C:\...\Temp\dsh_asr_xxx.wav: Permission denied
     ffmpeg 退出码 4294967283
根因：本机文件沙箱只允许写工作区（同 AGENTS §6.11 ③）
修：临时文件落 <REPO>\.frames\，用完即删
```

### ② 资产对象只有 `{id, name}`，没有 `rel`

```
现象：点「从音轨识别」→「文件不存在」
根因：我用 a.name 当路径 ⇒ 拿到显示名 asr2.mp4，
     而磁盘上是 wb_asr2_xxxxx.mp4（上传时加了前缀）
修：从 id 剥掉 "input:" / "output:" 前缀拿真实文件名
```

### ③ 断言自己过期（两处）

```
captions 里「字幕有背景衬底」—— 现在改成描边了，这条保护的是错误状态
captions 里「没有自动识别假入口」—— 现在真有识别能力，onClick={transcribe} 是真功能
```
两处都改掉了。这是 AGENTS §3.7 的常客：**方案变了，断言要跟着改。**
