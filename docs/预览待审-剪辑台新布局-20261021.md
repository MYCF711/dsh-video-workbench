## 五 · 预览阶段修掉的两个真 bug

**① 更多菜单点开立刻消失**

第一次点击能开，但 `document` 的 click 监听器用冒泡，把刚打开的菜单又关了。

修法（实装照这个来）：
```js
document.addEventListener('click', (e)=>{
  if (moreMenu.contains(e.target) || moreBtn.contains(e.target)) return;
  closeMenu();
});
```
而不是靠 `stopPropagation` —— 它在冒泡阶段不够可靠。

**② 菜单里的快捷键标注溢出到菜单外**

第一次用了 `.row .lbl{width:70px}` 的固定标签宽，剩下的空间装不下 `Shift Del`。
改成菜单专用类 `.menu-row`，用 `justify-content:space-between` +
`flex:1;min-width:0` 的 `.mn`，实测 `overflow: -10`。
