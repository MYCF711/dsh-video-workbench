# 跨模块状态字段的三个漏网点

### 6.38 ★「修了一半」比「没修」更隐蔽（2026-10-19）

```
★★ 两个真缺陷，同一个模式：**源头修了，调用方没接。**

① lost 状态没被接住（bridge 侧已修）
   bridge 的 job()（src/index.js:469）：
     任务既不在 running 也不在 pending，且没有 history
     → { completed: false, statusStr: "lost", lost: true,
         reason: "任务已不在 ComfyUI 队列里…" }
     注释写得很清楚：「2026-10-18 修（质检 P1-2『中断后永久轮询』）」

   但 dsh-editor 的轮询器（index-host.mjs:713）只判 h.completed：
     if (h.completed) { completeJob() } else { progressJob() }
   ⇒ lost 被当成「还在跑」→ progressJob() → status 停在 running

② error 状态没被接住（comfy.mjs 侧的语义错）
   comfy.mjs:170 原实现：
     completed: Boolean(status.completed) || status.status_str === "success"
   ⇒ ComfyUI 对【失败】也写 history，status_str = "error"，但 completed 算成 false
   ⇒ 同样被当成「还在跑」

★★ 后果链（实测）：
     clip 永久停在 running
       → summary.running 永远 ≥ 1
       → exportable 永远 false
       → 用户导不出片，界面显示「生成中」，无从判断

✅ 修法（两处）：
   comfy.mjs —— 修正 completed 的语义：
     completed: Boolean(status.completed) ||
       ["success", "error", "failed", "cancelled"].includes(status.status_str)
     ★ completed 应该表示「结束了吗」，不是「成功了吗」。

   index-host.mjs —— 三段判断：
     const okEnd  = h.completed && (h.statusStr ?? "success") === "success";
     const badEnd = h.completed && !okEnd;
     if (okEnd)       completeJob()
     else if (badEnd) failJob(`生成失败（ComfyUI status=${h.statusStr}）`)
     else if (h.lost) failJob(h.reason ?? "任务已不在队列里")
     else             progressJob()

★ 实测验证（用 interrupt 打断任务）：
   修复前 → { completed:false, statusStr:"error" } → status=running → 永久卡住
   修复后 → { completed:true,  statusStr:"error" } → status=failed
            regenError="生成失败（ComfyUI status=error）"
            summary: running=0, failed=1

★★ 为什么这条值得单独记：
   「修一半」比「没修」更隐蔽 —— 源头的注释会让人以为已经解决了。
   看代码时看到 bridge 里有 lost 分支 + 详细的修复注释，
   很自然会认为「这个坑已经填了」，但填的是下游看不到的那一端。

★ 通用判据：
   凡是**跨模块传递的状态字段**（completed / statusStr / lost），
   必须回答三个问题：
     1. 生产方：什么情况下产出这个值？
     2. 消费方：拿到每个值分别做什么？
     3. 有没有「生产方能产出但消费方没处理」的值？
   ⇒ 第 3 问是漏网之鱼最常见的地方。

★ 已固化验收：verify-agent-progress.mjs 的第 ⑨ 组（34/34）
   ✅ 成功结束 → complete   ✅ error 结束 → fail
   ✅ failed 结束 → fail    ✅ cancelled 结束 → fail
   ✅ lost → fail           ✅ 还在跑 → progress
