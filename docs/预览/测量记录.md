## 二 · ★ 与方案书不一致的两处（已按实测为准）

### 2.1 控件边框与底色

| 项 | 方案书 §3.1 | 实测官方 | 预览采用 |
|---|---|---|---|
| border | `1px solid var(--dsw-alias-border-l2)` | **0px none** | **0px** |
| background | `var(--dsw-alias-bg-layer-2)` | **transparent** | **transparent** |

**理由**：`--dsw-alias-bg-layer-2` 在浅色主题下解析为 `#fff`，与参数条所在的白色面板同色。
按方案书写等于「白色底 + 白色底 + 1px 淡边框」，控件边界只剩一条 `#0000001a`（约 10% 黑），
而官方是用 **hover 变色**来标示可点。照官方做，视觉更统一，且暗色主题自动成立。

### 2.2 `--dsw-focus-ring-color` 实际解析为 `transparent`

方案书 §3.3 把它列为「已实测存在」。实测：它**存在但值为 `transparent`**。

```
404 个 --dsw-* token 中，只有 2 个解析为空：
  --dsw-focus-ring-color   = transparent
  --dsw-hovercard-bg       = 未定义
```

DSH 自己的 CSS 也是回退的：

```css
:focus-visible {
  outline-color: var(--dsw-focus-ring-color, var(--dsw-alias-state-business-primary));
}
```

⇒ **预览用 `--dsw-alias-state-business-primary`（#4176e6），不用 focus-ring-color。**

## 五 · 布局踩到的两个真坑（都靠测量抓到，不是看出来的）

### 5.1 grid 项默认 `stretch` 把按钮拉成整列宽

`.wb-bar` 用 `auto` 列放按钮时，「生成」按钮被拉到 **218.66px**，与工作流下拉同宽。

修：`justify-items: start`（并让 `.wb-field` 自己 `width:100%` 撑满列）。

### 5.2 参数条有 7 个直接子元素，第 7 个自动换行

开关 + 生成 + 取消让子元素变成 7 个，超出声明的 6 列 →
「生成」按钮折到第二行（y=157，其余 y=121）。

修：把「开关 + 生成 + 取消」打包进第 6 列的 `.wb-actions` flex 容器，
并显式 `grid-template-rows: var(--wb-bar-height)`。

**判据（可复跑）**：六个槽的 `getBoundingClientRect().y` 必须全部相等。

### 5.3 `minmax(0,…)` 的两面性

- `minmax(0,…)` → 560px 视口下画幅列只剩 62.9px，`9:16` 被裁
- `minmax(64px,…)` → 560px 视口下总宽超出，出现横向溢出（**更糟**）

正解是第三种：保留 `minmax(0,…)`（永不溢出），靠 `@media (max-width:700px)`
缩短文案（「10 秒」→「10」）并压缩种子框/间距。

## 六 · 数据真实性核对

预览里的 4 个工作流与参数选项，全部取自 19499 实机 `/comfy-bridge/modes`：

```
yz           多参 H3 ★   aspect=16:9 dur=5 steps=10  toggles=[wudA]        media=10
krea2        Krea2 生图   aspect=16:9            steps=8   toggles=[secondPass,redraw,loraChain]
qwen21       Qwen 生图    (无 aspect/dur 默认)    (无 steps 默认)  toggles=[]
qwen21-edit  Qwen 改图    (无 aspect/dur 默认)    steps=25  toggles=[]  media=2
```

★ 交叉核对 bind 文件后的真实约束（预览据此置灰，不假装支持）：

| 工作流 | bind 里有 `durationSec` 吗 | 有 `aspect` 吗 |
|---|---|---|
| `yz` | ✅ `vars.durationSec` → 259.value | ✅ `vars.aspect` → 252.aspect_ratio |
| `krea2` | ❌ 无 | ✅ `vars.aspect` → 211.aspect_ratio |
| `qwen21` | ❌ 无 | ✅ `vars.aspect` → 406.aspect_ratio |
| `qwen21-edit` | ❌ 无（用 width/height） | ❌ 无（用 width/height 459:456） |

⇒ 预览里「时长」在三个生图工作流下置灰并给 `title` 说明原因；
「画幅」在 `qwen21-edit` 下置灰。**置灰而非隐藏**——隐藏会让 grid 列宽跳动。

## 七 · 未验证项

- **暗色主题**：方案书要求亮色预览，未测暗色下的表现。所有色值走 token，
  理论上自动跟随，但**没跑过**。
- **Safari / Firefox**：只用 Edge（Chromium）测过。`appearance:none`、
  `::-webkit-inner-spin-button` 等是 Chromium 路径。
- **真实实例里的 slot 渲染**：预览是独立 HTML，未在 DSH 的 `conversation.view`
  slot 内实际渲染过。实装后需再做一轮「实装 vs 定稿预览」对照。
- **触摸屏 / 移动端**：未测。
