### C2 · 第二轮复核抓到并修掉的第 12 个静默失效：**高亮 0 次**

```
症状：消息条正确弹出两条，但 highlightEvents = 0（高亮从未加上去）
根因：调用顺序 + React 异步渲染
  agentSync 里：
    onSnapshot()    → syncSnapshotToEditor() → updateSceneTracks()
    onAgentChange() → highlightElements()   → querySelector('[data-element-id]')
  updateSceneTracks 只把数据交给 React，**DOM 要等下一帧才更新**
  ⇒ 紧接着同步执行的 querySelector 找不到新元素宿主
  ⇒ 静默 0 命中（「找不到就跳过」是合法分支，不报错）

修法两条：
  ① 高亮推到 DOM 更新之后：requestAnimationFrame 套 requestAnimationFrame
  ② highlightElements 返回值从 number 改成 {hit, missing}，
     client 在 hit===0 时打 console.warn
     —— 原来返回裸数字、调用方也不看，所以「0 命中」和「全命中」外部无法区分，
        这正是它坏掉却没被发现的原因
```

## 五 · 本轮踩坑清单（全部已进 Hindsight）

1. esbuild 把裸 `require` 换成 `__require` 桩（`typeof require` 判定通过但调用必抛）
2. `forwardRef` 的 `typeof` 是 `"object"`，用 `typeof === "function"` 判会误判
3. **ArtCraft 与 dsh-editor 是两套 tracks 结构**（clips vs elements、in/out vs startTime/duration）
   —— 今天同一个错误踩了三次
4. `--dsw-alias-bg-layer-2` 浅色下 = `#fff`（与面板同色 ⇒ 看不见）
5. grid item 写 `align-self` ⇒ auto 行高塌成 `0px`，卡片重叠
6. `useMemo` 依赖里放回调才赋值的派生字段 ⇒ TDZ（minify 后只剩 `'k'`）
7. `const` 函数定义在 `if(...) return` 之后 ⇒ 同款 TDZ
8. 面板写了但没入口（检查器）⇒ 功能存在但打不开
9. **CSS 注释里不能有反引号**（外层是模板字符串）—— 连踩两次
10. 用 PowerShell 按下标切片重排大段代码 ⇒ 把 `ShortcutSettings.js` 切坏，只能整文件重写
11. 验收断言匹配到**注释里的示范文本** ⇒ 3 条假红（判「代码里有没有 X」必须先剥注释）
12. **轮询只更新计数、不灌数据进编辑器** ⇒ 消息条与高亮永不触发（实测 `updateSceneTracks` 0 次调用）
13. **「待生成」镜头有意不投影** ⇒ 验证 Agent 反馈必须做「add-shots + replace-clip」两步，
    只做 add-shots 会误判成「同步坏了」
14. **高亮在 DOM 更新前执行** ⇒ 静默 0 命中（`updateSceneTracks` 是异步渲染）
    —— 且因为 `highlightElements` 返回裸数字、调用方不看，这个失效完全不可观测
