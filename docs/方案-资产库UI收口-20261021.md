## 零 · 一句话

**资产卡的操作区比卡片本身还宽 76%，六个控件压在隔壁卡片上 —— 先把它收回来，再谈视觉。**

## 零之二 · 实测问题（不是猜的）

### 问题 1 · 操作区溢出卡片（最严重，功能性缺陷）

```
卡片宽            202px
操作区控件总宽    356px
⇒ 超宽 154px

实测溢出（卡片右边界 630）：
  项目文件夹   右 646   超出  16px
  ✨判断归属    右 675   超出  45px
  ＋角色       右 722   超出  92px
  @引用        右 752   超出 122px
  改名         右 777   超出 147px
  删除         右 802   超出 172px

flex-wrap: nowrap  ⇒ 不换行，直接压到隔壁卡片
```

**后果**：用户想点某张卡的「删除」，实际点到的是右边那张卡的操作区。
这不是「不好看」，是**点错对象**。

### 问题 2 · 七个控件一字排开，没有主次

```
参考用途(SELECT 145px) | 项目文件夹(SELECT 65px) | ✨(27) | ＋角色(45) | @引用(28) | 改名(23) | 删除(23)
```

**高频**：@引用、改用途
**低频**：改名、删除、判断归属、＋角色
**信息展示**：项目文件夹（是个状态，不全是操作）

现在它们同权重排列，用户要在 7 个里找 1 个。

### 问题 3 · 空态引导与实际不符

截图显示空态区已有「从资产库引一张 / 直接写提示词」两个按钮，
但**没有说明「资产库在哪、有多少、怎么管理」**。
主人打开面板前，不知道里面有 875 项。

### 问题 4 · 没有「我改过什么」的反馈

改用途、改文件夹、改名后，界面没有即时确认。
用户不确定「到底存了没有」。

## 一 · 目标与非目标

### 目标

```
① 资产卡操作区零溢出（任何分辨率下都不压到隔壁卡）
② 七个控件分主次：高频的显眼，低频的收进「更多」
③ 空态引导说清楚「资产库是什么、有多少、怎么用」
④ 每次改动有 1.2s 的可见反馈（toast），但不打断操作
⑤ 暗色/亮色都合规（对比度 ≥ 4.5:1）
```

### 非目标

```
✗ 重写资产库            → 只改卡片操作区的呈现，不动数据流
✗ 换 UI 框架            → 继续用现有 h() 无 JSX 方案
✗ 加动画库              → 只用 CSS transition
✗ 改卡片尺寸/网格列数    → 那会牵动画布视野计算（§6.27 的坑）
✗ 新增功能              → 本方案只做减法与分层
```

## 二 · 怎么改（三条）

### 改动 1 · 操作区分两层（核心）

```
第一层（常显，最多 3 个）：
  [参考用途 ▾]  [@引用]  [更多 ▾]

第二层（点「更多」弹出，5 个）：
  项目文件夹 ▾
  ✨ 判断项目归属
  ＋角色
  改名
  删除
```

**为什么这样分**：

| 控件 | 频率 | 理由 |
|---|---|---|
| 参考用途 | 每次生成前 | 直接决定 H3 标签，最高频 |
| @引用 | 每次生成前 | 核心动作 |
| 更多 | — | 收纳低频 |
| 项目文件夹 | 建项目时一次 | 设完就不动 |
| ✨判断归属 | 入库时一次 | 同上 |
| ＋角色 | 建角色卡时 | 低频 |
| 改名 | 入库时一次 | 低频 |
| 删除 | 极少 | 危险操作，应该藏深一点 |

**「更多」用 popover**（不用 `window.confirm`，不用新开面板）：
- 绝对定位在卡片内，不超出卡片边界
- 点外面关闭
- Esc 关闭

### 改动 2 · 宽度自适应

```
第一层三个控件的宽度按容器算：
  参考用途  flex: 1 1 auto   min-width: 0（可压缩）
  @引用     flex: 0 0 auto
  更多      flex: 0 0 auto

flex-wrap: nowrap 保留，但内容总量已降到 202px 以内
```

**硬约束**：`参考用途` 当前显示的中文最长是「物品/道具外观」（7 字），
设 `min-width: 0` + `text-overflow: ellipsis`，超长时省略号，不撑破卡片。

### 改动 3 · 轻量反馈

```
改用途/文件夹/名成功后：
  卡片操作区右侧浮出 1.2s 的「已存」小字（opacity 0→1→0）
  ★ 不用 alert、不用弹窗、不打断下一步操作
```

## 三 · 空态引导改什么

现在（截图实测）：

```
[🗂 从资产库引一张]  [直接写提示词]
```

改成：

```
还没有产物
生成的图和视频会自动出现在这里，不用刷新

[🗂 从资产库引一张（875 项）]  [直接写提示词]

拖空白平移 · 滚轮缩放 · 点卡片放大
```

**只加一个数字**（875），让人知道里面有东西。
**这个数字必须从 API 实时取**，不能写死 —— 否则就是谎话（AGENTS §6.40 判据二）。

## 四 · 验收标准（可测量）

| # | 标准 | 怎么测 |
|---|---|---|
| 1 | 所有控件右边界 ≤ 卡片右边界 | `getBoundingClientRect()` 逐个比对 |
| 2 | 第一层控件 ≤ 3 个 | 数 DOM |
| 3 | 「更多」popover 不超出卡片 | 同上 |
| 4 | 点外面/Esc 能关 popover | 派发事件后检查 DOM |
| 5 | 7 个功能全部仍可达 | 逐个点一遍 |
| 6 | 空态显示实时资产数 | 与 `/library` 返回的 count 比 |
| 7 | 暗色/亮色对比度 ≥ 4.5:1 | 算 WCAG |
| 8 | 34 套回归不破 | `node verify-all.mjs --static` |
