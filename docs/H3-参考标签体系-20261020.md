## 一、四种标签（官方原文第 26-33 行）

| 标签 | 官方英文原文 | 中文 |
|---|---|---|
| `<Subject N>` | Visible content abstracted from reference assets that can be reused or modified in the target video | 从参考资产抽象出的、可在目标视频中复用或修改的可见内容 |
| `<Picture N>` | A reference image used as a concrete target frame or shot-planning anchor | 用作具体目标帧或分镜规划锚点的参考图 |
| `<Video N>` | A reference video that provides an editing source, continuation starting point, or whole-video temporal structure | 提供编辑源／续接起点／整片时序结构的参考视频 |
| `<Audio N>` | An audio signal that is copied or referenced | 被复制或引用的音频信号 |

**跨节一致性（第 35 行）**：
> Once a reference label is assigned to a piece of content, it keeps the same meaning across `subject_definitions`, `summary`, `retention_analysis`, `detailed_description`, and the audio sections.

## 二、`<Subject N>` 的完整范围（第 41-48 行）

官方列举的四组：

```
· People, animals, or objects                     人、动物、物体
· Scenes, backgrounds, or environments            场景、背景、环境
· Clothing, props, interfaces, or visual effects  服装、道具、界面、视觉特效
· Styles, actions, expressions, or poses          风格、动作、表情、姿势
```

**关键定义句（第 48 行）**：
> It represents a content unit that will actually be used in the target video, rather than the source file itself. One subject may be defined by multiple reference assets, and one reference asset may provide multiple subjects.

⇒ **一个 `<Subject>` 可以由多个资产定义；一个资产也可以提供多个 `<Subject>`。**
这是「多对多」，不是「一图一 Subject」。

### 官方示例（第 51、57 行）

```text
<Subject 1> is the young woman in <Picture 1>, with long dark hair,
a blue cardigan, and a thin silver necklace.

<Subject 1> is the woman whose appearance comes from <Picture 1>
and whose walking motion comes from <Video 1>.
```

★ 第二个例子是「外观来自图 + 动作来自视频」合成一个 Subject ——
这正是现有的 `appearance` + `motion` 应该合并到 Subject 的依据。

## 三、`<Picture N>` 的用法（第 60-74 行）

### 单独开 `<Picture N>` 的场合（第 62 行）

> Use a standalone `<Picture N>` when the reference image itself serves as a shot's
> **first frame, keyframe, last frame, edited keyframe, or composition anchor**

```
首帧 / 关键帧 / 尾帧 / 编辑后的关键帧 / 构图锚点
```

### ★★ 不能单独开 Picture 的场合（第 68 行，最重要的一条）

> If an image is used **only to define a character, scene, costume, or style**,
> **do not create a standalone picture entry**. Instead, cite the image source
> inside the corresponding `<Subject N>` definition.

```
只用来定角色 / 场景 / 服装 / 风格 的图
  ⇒ 不许单独开 <Picture N>
  ⇒ 必须并进对应 <Subject N> 的定义里
```

**这一条否掉了「外观图也当 Picture」的写法。**

### 分镜图（第 72-73 行）

> When an image acts as a storyboard or shot-planning reference, state which shots
> it maps to and what planning information it provides:

```text
<Picture 3> is a storyboard reference for [Shot 1] and [Shot 2],
defining their viewpoint, subject placement, and shot order.
```

⇒ **分镜图属于 `<Picture N>`，而不是 Subject。** 这是它和「角色外观图」的分界。

## 四、`<Video N>` 的用法（第 76-88 行）

用途（第 78-82 行）：
```
· Editing an original video                              编辑原视频
· Continuing from the end of an original video           从原视频末尾续接
· Referencing the original video's camera movement,
  cuts, rhythm, or temporal structure                    引用运镜/剪辑/节奏/时序结构
```

**★ 边界（第 88 行）**：
> If a person, object, scene, action, or effect from a reference video is reused
> as visible content, **it still belongs under `<Subject N>`**.
> `<Video N>` identifies the asset or structural source and does not replace subject labels.

⇒ 从视频里取一个人物长相 → 那是 `<Subject N>`，不是 `<Video N>`。
`<Video N>` 只标「这个视频是结构来源」。

---

## 五、`<Audio N>` 的用法（第 90-119 行）

用途（第 94-98 行）：
```
· Copying all or part of an audio signal              复制音频信号
· Referencing a background-music style                引用 BGM 风格
· Referencing a speaker's voice timbre and delivery   引用音色与表达
· Using dialogue, lyrics, or sound effects            使用对白/歌词/音效
· Referencing beat, rhythm, or audio continuity       引用节拍/节奏/连续性
```

### ★ 编号独立（第 110-112 行）

> `<Video N>` and `<Audio N>` are numbered **independently**. Each index indicates
> only the label's order within its own category and does not encode a pairing.
> The same reference video may therefore correspond to `<Video 1>` and `<Audio 2>`.
>
> **An ordinary reference video does not create `<Audio N>` merely because the file contains sound.**

⇒ 一个带音轨的 mp4：
  - 作为结构来源 ⇒ `<Video 1>`
  - 它的音轨【不会】自动变成 `<Audio N>`，除非你明确要复制那段音频

### 说话人编号（第 100 行）

> When an `<Audio N>` explicitly corresponds to a target speaker, reuse that
> speaker's **global ID** in the definition: write `<Subject N> (Sx)` when the
> speaker maps to a defined subject, or use a stable voice description followed
> by `(Sx)` otherwise.

```text
<Audio 1> is the voice-timbre reference for <Subject 1> (S1).
```

## 六、由此得出的分类表（本项目的实现依据）

### 6.1 一级分类 = H3 的四个标签（不许多也不许少）

| id | 标签 | 可接受的素材 |
|---|---|---|
| `subject` | `<Subject N>` | 图 / 视频 |
| `picture` | `<Picture N>` | 图 |
| `video` | `<Video N>` | 视频 |
| `audio` | `<Audio N>` | 音频 |

### 6.3 主人提的五种参考 → 本表的映射

| 主人说法 | 落到 | 说明 |
|---|---|---|
| 角色参考 | `subject.character` → Subject | |
| 骨骼图参考 | `subject.pose` → Subject | |
| 物品外观参考 | `subject.object` → Subject | |
| 关键帧 | `picture.key` → Picture | |
| 分镜图 | `picture.storyboard` → Picture | |

**⚠ 不能按「角色/骨骼/物品/关键帧/分镜」建五个一级分类** ——
前三者官方都归 `<Subject>`，强行分开会导致生成的提示词里出现
「同一个 Subject 被写成三个」这种错误。
