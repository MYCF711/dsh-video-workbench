
**这就是主人说的「会话右上角这个空位」。**
现在那里有「文件资源管理器」按钮（`Dc7zOa_headerUtilities`, x=1785 w=79）——
它是这个 slot 的现有占用者，我们的东西可以并排加进去。

| slot | 位置 | 用途 |

| `conversation.session.header.utilities` | ★ 会话右上角 | **资产库按钮放这里** |

## 三 · 因此的架构修正

### 原来的错误做法

```
自己画一整套：左栏 + tab 行 + 预览 + 工具栏 + 时间轴 + 检查器
⇒ 城中城
```

### 正确做法

```
剪辑台 = 注册进 conversation.view 的一个视图（这本来就是现有做法，保留）
└── 视图内容只画【DSH 没有的部分】：
    预览 / 工具栏 / 时间轴 / 检查器
    —— 这些是剪辑功能本身，DSH 没有对应物，必须自己画

资产库 = 注册进 conversation.session.header.utilities（右上角那个空位）
    —— 一个按钮 + 点开后的面板，跟「文件资源管理器」并排

快捷键设置 = 注册进 settings.section（DSH 设置面板里加一节）
    —— 复用 DSH 设置面板的外壳，不自己画弹窗

Agent 操作反馈 = 走 conversation.session.header.actions 或 composer.dock
    —— 用 DSH 已有的消息位，不自己画 toast
```

**判据：凡是 DSH 已经有外壳的地方（设置、右上角、dock、右栏），
我们只塞内容进去；凡是 DSH 没有的地方（时间轴、预览），自己画。**

## 四 · 主人举的例子正是在说这个

> 「就像我们之前把状态监控加入到了最底部的dsh原生状态监控一样」

实测确认：`ComfyDockStatus` 注册在 `conversation.composer.dock`，
`order: -10`（排在 token 统计左边）。它没画自己的底栏，是**塞进 DSH 的底栏**。

> 「是不是可以在会话右上角这个空位利用起来，放我们的资产库位置？
>   学这个文件资源管理器选择一样，做一个资产库」

⇒ 资产库应该注册到 `conversation.session.header.utilities`，
做成一个和「文件资源管理器」相邻的按钮 + 面板。
