## 三 · 主人建好后我执行的命令（已备好，一条不差）

```powershell
cd "<REPO>"

# 1. 确认本地干净
git status --short

# 2. 加 SSH remote（不用 token，SSH 已验证可用）
git remote add origin git@github.com:MYCF711/dsh-video-workbench.git

# 3. 确认分支名
git branch -M main

# 4. 推（如果仓库是空的，直接推）
git push -u origin main

# 5. 核对远端
git ls-remote --heads origin
```

## 五 · 如果远端已经存在内容

如果 `git push` 报 `non-fast-forward`，说明仓库不是空的：

```powershell
# 先看远端有什么
git ls-remote origin

# 如果远端只有一个自动生成的 README，可以合并
git pull --rebase origin main
git push -u origin main
```

若远端有重要内容，**停下来问主人**，不覆盖。
