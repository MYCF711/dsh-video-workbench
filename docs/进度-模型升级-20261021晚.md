## 一 · 网络实测（Python，不用 PowerShell）

**为什么不信 PowerShell**：它的 `Invoke-WebRequest` 对所有站点都报「超时」，
但同一台机器 Python 能下载 463MB 模型。PowerShell 的结论在本机不可信。

| 站点 | 带证书校验 | 不校验 |
|---|---|---|
| huggingface.co | 超时 | 超时 |
| cdn-lfs.huggingface.co | 超时 | 超时 |
| **hf-mirror.com** | **200（8.7s）** | **200（8.0s）** |
| modelscope.cn | 200（15.5s） | 200（15.4s） |
| 腾讯云 pypi | 200（0.3s） | 200（0.2s） |
| 中科大 pypi | 403 | 403 |
| pypi.org | 200（33s） | 200（24s） |

⇒ **huggingface.co 本身不可达**，但 **hf-mirror 可达**。
⇒ 主人的「网络没受限」在「能访问」这层是对的（hf-mirror 通），
   但**带宽极低**：实测下载速率 **0.05 ~ 0.1 MB/s**。

## 二 · 下载路径的两个坑

### ① `huggingface_hub` 的 Xet 通道会 401

```
FAIL: RuntimeError: Task error: File reconstruction error:
      CAS Client Error: HTTP status client error (401 Unauthorized),
      domain: https://cas-server.xethub.hf.co/v2/reconstructions/...
```

新的 `huggingface_hub` 默认走 XetHub 的 CAS 加速，
而 hf-mirror 没代理那个域 ⇒ 401。

**但传统 LFS 直链是通的**（实测 HEAD 全部 200）：
```
https://hf-mirror.com/<repo>/resolve/main/model.bin  →  200, 1457 MB
```

⇒ 解法：直接按 LFS 直链下，手工摆成 huggingface_hub 认的缓存结构。

### ② 缓存结构可以简化

huggingface_hub 的标准布局是 `blobs/<sha>` + `snapshots/<rev>/` 软/硬链接。
本地空间够（22.7GB），**直接把实体文件放进 snapshots 就行**，
不用做 blobs 硬链接 —— huggingface_hub 读缓存时认实体文件。

```
.models/whisper/models--<repo>/
    snapshots/main/config.json
    snapshots/main/tokenizer.json
    snapshots/main/vocabulary.json
    snapshots/main/model.bin
    refs/main                    ← 内容就是 "main"
```

## 四 · 已经做好的：模型自动选择

既然要换模型，就不能把模型名写死。已改为：

```js
// host 侧 lib/index.js
String(config.whisperModel ?? body.model ?? "auto")
```

```python
# python 侧按能力优先级挑【本地已存在】的
cands = [
    ('large-v3-turbo', 'deepdml/faster-whisper-large-v3-turbo-ct2'),
    ('medium',         'Systran/faster-whisper-medium'),
    ('small',          'Systran/faster-whisper-small'),
]
# 判断标准：model.bin 存在且 > 100MB
#（只下了 config/tokenizer 的空壳不算 —— 这次 medium 就踩了这个）
```

响应里也返回实际用的模型名（`model` 字段）。

**实测验证**（turbo 还没下完时）：
```
POST /comfy-assets/transcribe
→ ok=true  model=small  段数=1  full=依旧是吗
```
⇒ 正确回退到 small，说明机制有效。turbo 下完会自动切过去，**不用改代码**。
